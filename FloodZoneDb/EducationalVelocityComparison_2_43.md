# Этап 2.43 — учебное сравнение скоростей

Этап 2.43 является описательным учебным сравнением реальных Velocity из Excel с V_calculated учебной модели. Результат не является верификацией методики, калибровкой или доказательством физической применимости модели.

## Метод сравнения

`ObservedVelocity` взят из сохранённых в PostgreSQL учебных точек, сопоставленных по `SourceIsodatId` с исходными Velocity-записями таблицы `isodats`. Профиль определяется парой `CrossSectionNumber + Side`. Для каждого профиля агрегированы все исходные Velocity-записи — по 6 на профиль, 36 всего.

`V_calculated` взят из результата полной учебной цепочки этапа 2.42: геометрия 2.41 и параметры 2.42 без повторного или альтернативного расчёта скорости этим этапом. Значения не подбирались под наблюдения.

Точечное сопоставление Depth и Velocity по индексу или координате `X` не выполнялось. Количество записей различается; совпадающие `X` не объединялись и не удалялись. Использовано только сравнение на уровне профиля: Min/Max/Mean всех его Velocity-наблюдений с единственным `V_calculated` того же профиля.

Формулы:

```text
Difference = ObservedVelocityMean - V_calculated
AbsoluteDifference = abs(Difference)
RelativeDifference = AbsoluteDifference / abs(V_calculated), если V_calculated != 0
Ratio = ObservedVelocityMean / V_calculated, если V_calculated != 0
```

`RelativeDifference` и `Ratio` в таблице приведены как безразмерные отношения, не как проценты. При нулевом `V_calculated` обе величины остаются неопределёнными; epsilon не используется.

## Описательные итоги

- Во всех 6 профилях `V_calculated` меньше `ObservedVelocityMean` (`Difference > 0`).
- Ни в одном профиле `V_calculated` не больше `ObservedVelocityMean`.
- Максимальное абсолютное расхождение: створ 2, Right — `2.430697`.
- Максимальное относительное расхождение: створ 3, Right — `565.639880`.
- Эти наблюдения описывают только полученные числа и не объясняют физические причины и не оценивают правильность модели.
