# Этап 2.42 — учебная полная гидравлическая цепочка

Этап 2.42 является учебным синтетическим расчётом. Реальные Depth и Velocity взяты из импортированного набора «Орешко Волга», однако правила Ri → X, Depth → h, а также параметры g, nu, h, If и B являются учебными допущениями и не являются восстановлением официальной методики.

Результаты ниже относятся только к `EducationalSynthetic`. Они не являются официальным расчётом, контрольным расчётом «Орешко Волга» или доказательством методической связи Excel-профилей с `BankPoints` / `CrossSectionGeometry`.

## Входы и формулы

Для каждого профиля `CrossSectionNumber + Side` геометрические значения `Omega`, `Chi` и `HydraulicRadius` получены калькулятором этапа 2.41 при `EducationalWaterDepth = 5.0`. Полный калькулятор принимает результат 2.41 как вход и не пересчитывает геометрию.

Учебные входные параметры одинаковы для всех профилей:

| Параметр | Значение | Источник |
|---|---:|---|
| `g` | 9.81 | Синтетическое учебное допущение |
| `nu` | 0.00000115 | Синтетическое учебное допущение |
| `h` | 5.0 | Синтетический учебный уровень глубины 2.41 |
| `If` | 0.001 | Синтетическое учебное допущение |
| `B` | `MaxX - MinX` | Синтетическая ширина профиля по принятому `X = Ri / DistanceM` |

Прямые формулы полного учебного расчёта:

```text
R = Omega / Chi
vStar = sqrt(g * R * If)
C = 5.25 * sqrt(g)
    * sqrt(nu / (g * nu)^(1/3))
    * (h / B)^(1/6)
V_calculated = C * sqrt(R * If)
Q = V_calculated * Omega
```

`ObservedVelocityMin` и `ObservedVelocityMax` вычислены отдельно по исходным Velocity-точкам того же профиля. Наблюдаемая скорость не подставляется в формулу `V_calculated` и не влияет на гидравлический результат. `CalculatedFloodDuration` и `ActualFloodDuration` не читаются расчётчиком и физически не интерпретируются.

## Путь данных и ограничения

Проверенный путь получения данных:

```text
PostgreSQL isodats (360 записей)
→ IsodatPostgresRepository.LoadAsync
→ IsodatGrouper
→ isodat_hydraulic_points (84 сохранённые учебные точки)
→ EducationalDepthProfileGrouper (6 профилей)
→ расчёт геометрии этапа 2.41
→ отдельный EducationalFullHydraulicCalculator
```

В сохранённом учебном наборе присутствуют 48 Depth и 36 Velocity-записей. На каждый из шести профилей приходится 8 Depth и 6 Velocity точек. Учебный полный результат хранится только в памяти. Производственные `BankPoints`, `CrossSectionGeometry`, calculators, таблица `isodats`, Excel import и PostgreSQL schema этим этапом не изменялись; новая таблица результата не создавалась.

## Вывод

Полная цепочка `Omega → Chi → R → vStar → C → V_calculated → Q` реализована только для изолированного учебного синтетического слоя и применена к шести Depth-профилям. Наблюдаемые Excel-скорости сохранены отдельно, временные поля не использовались. Ни один результат этого этапа не является восстановлением официальной методики.
